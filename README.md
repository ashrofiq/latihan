# Jejak Latihan: pasang lewat Chrome (GitHub Pages)

## Cara menerbitkan (sekali saja)
1. Buat repositori GitHub baru, misalnya `jejak-latihan`. **Pilih Public.**
   GitHub Pages gratis hanya untuk repositori Public. Repositori ini tidak berisi data pribadi
   atau kunci, hanya aplikasinya. Data latihanmu tersimpan di HP-mu, bukan di sini.
2. Unggah **seluruh isi folder ini**, termasuk folder `.github`.
3. Di repositori: **Settings, Pages, Build and deployment, Source: GitHub Actions**.
4. Buka tab **Actions**, pilih **Terbitkan ke GitHub Pages**, lalu **Run workflow**
   (juga berjalan otomatis tiap ada perubahan).
5. Setelah hijau, alamat aplikasimu: `https://NAMA-GITHUB.github.io/NAMA-REPOSITORI/`

## Memasang di HP (Chrome Android)
1. Buka alamat di atas di Chrome.
2. Ketuk menu ⋮ lalu **Instal aplikasi** (atau **Tambahkan ke layar utama**).
   Di aplikasi, buka **Setelan** lalu **Pasang di layar utama**. Jika Chrome siap, ada tombol **Pasang sekarang**.
3. Ikon Jejak Latihan muncul di layar utama dan terbuka seperti aplikasi biasa.
   Setelah dibuka sekali dengan internet, aplikasi juga bisa dipakai tanpa internet.

## Memperbarui
Ganti `index.html` dengan versi terbaru lalu unggah. Situs terbit ulang otomatis.
Di HP, buka aplikasi dengan internet menyala: versi baru terpakai saat dibuka ulang
(akan muncul pemberitahuan "Versi baru siap").

## Catatan penting
- **Data tersimpan di HP**, terpisah untuk setiap cara pakai. Data di aplikasi web, di APK, dan
  di file HTML yang dibuka langsung **tidak saling terhubung**. Untuk memindahkan data,
  pakai **Setelan, Salin cadangan** lalu **Pulihkan dari teks** di tempat tujuan.
- Menghapus data situs di Chrome atau menghapus aplikasi menghilangkan datanya. Cadangkan berkala.
- Semua situs `NAMA-GITHUB.github.io` berbagi alamat induk yang sama. Data aplikasi ini tidak
  tercampur dengan aplikasi lain karena memakai nama penyimpanan sendiri.
